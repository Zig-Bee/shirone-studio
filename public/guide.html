QUICK START

第一次使用

本地编辑

  1. 使用 Chrome、Edge 或其他 Chromium 浏览器打开编辑器。
  2. 点击“Work with Local Repository”。
  3. 选择 /Users/huyan/Code/shirone-content 文件夹。
  4. 编辑并保存后，内容会直接写入本地内容仓。

云端编辑

  1. 打开线上编辑器并点击 Sign In with Token。
  2. 按登录框中的 GitHub 链接创建令牌；令牌只授予 Zig-Bee/shirone-content 内容读写权限。
  3. 选择“文章”“说说”“固定页面”或“基础设置”进行编辑，保存会直接提交到私有内容仓。

文章图片

新文章使用 content/posts/文章名/index.md，封面和正文图片与文章放在同一个文件夹，正文使用 ./图片名.webp 引用。

本机同步与检查

在线保存后，先在 shirone-content 中执行 git pull，再到 Shirone 执行 pnpm content sync。完整中文说明已作为“Shirone Studio 使用指南”草稿加入文章列表。
