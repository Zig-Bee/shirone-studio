## 2026-09-05 · v0.2.0 / B01 · 配置驱动的团子首页

- **功能与目的：**站点资料成为名称与简介的公共来源；个人昵称、个人简介及横幅文案允许留空继承，避免重复修改。
- **运行天数：**从明确的建站日期计算，按站点时区过日界；缺失、非法或未来日期隐藏。浏览器会刷新天数，不依赖每天重新构建。团子使用 `2026-09-04`，当日为 0 天。
- **内容显示：**增加 `showDraftsInDev`；本地可选择和公开站点一致地隐藏草稿，生产始终隐藏。统计始终只计公开内容，空分类／标签卡片不显示；空文章列表显示“暂无数据”。
- **页面影响：**GitHub 指向 Zig-Bee；隐藏未配置的 Twitter、Steam、默认音乐及公告；导航先保留主页、归档、关于、GitHub；关于页采用团子资料。其他演示栏目只是移除入口，未删除其底层数据或路由。
- **验证：**日期边界及非法日期测试 2 项通过；Astro 检查通过。浏览器已确认真实首页的 GitHub 入口与运行 1 天，截图与最终回归结果见补记。
- **发布：**本地生效，尚未部署。主题署名和技术文章中的 Shirone 保留其原义。
