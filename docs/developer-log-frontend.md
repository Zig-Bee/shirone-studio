## 2026-09-05 · 0.0.1 后续修复 / B06 · CMS 正文更新停留旧版

- **问题：**CMS 修改正文后，文件已同步，但新增的 `updated: ''`、`updatedAt: ''` 不符合前端日期类型，Astro 热更新拒绝新文章并保留旧正文。
- **修改与目的：**可选日期将空字符串、空白和 null 视为未填写，非空非法值仍交给严格日期校验；同步按钮脚本放入独立作用域，避免 Swup 重复执行导致变量声明冲突。
- **页面影响：**文章中的 chiikawa 已能显示；同步成功（含已是最新）会重新加载页面，失败时保留现有页面。
- **验证：**日期空值与重复脚本执行 5 项回归通过；首页、归档、关于等无障碍检查 8 项通过；Astro 检查 0 错误、0 警告。真实 Chrome 直达文章及经首页返回文章均显示 chiikawa，无页面脚本错误。
- **版本：**保留 `v0.0.1` 原始标签，本修复作为后续提交记录。
