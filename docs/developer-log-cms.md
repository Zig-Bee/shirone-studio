## 2026-09-05 · v0.2.0 / B02 · 本地保存与预览一致性

- **功能与目的：**Studio 本地服务启动时自动监听内容仓，保存后串行更新预览副本、离线图标和说说缩略图；连续保存合并处理，同步中再次保存会补跑。
- **页面影响：**工作台每 5 秒刷新等待／更新中／已更新／失败状态；本地未提交修改不阻止预览。停止 Studio 服务即停止监听。
- **边界：**仅内容仓到主题副本单向更新，不反写生成文件，不自动提交、推送或拉取 GitHub；远程 CMS 保存后仍须检查部署。
- **验证：**10 项 Studio 测试通过，覆盖连续保存串行执行及失败恢复；实际内容文件保存触发更新已核验。
