# 团子 0.0.1 开发快照

日期：2026-09-05（Asia/Shanghai） · 批次：B05

## 版本含义

`VERSION` 中的 `0.0.1` 与 Git 标签 `v0.0.1` 表示团子项目的首次整体快照。Shirone 的 `package.json` 仍为上游主题版本，Studio 的包版本仍保留工具版本；二者不替代团子的整体版本号。Sveltia CMS 是外部引擎，不改它的版本或提交。

## 本次保存

- 前端：当天累积的身份展示、运行天数、草稿过滤、内容同步入口、图片路径及音乐配置修复；按仓库要求格式化代码。
- 内容：当前头像、背景、启用的音乐配置、已经重新开启的横幅打字循环，以及正式文章《团子建站第一天：从能打开，到能管理的 0.0.1》。
- Studio：基础设置表单、检查脚本、开发日志及模块映射。
- 内容分离后，主题取消跟踪的 141 个旧内容文件仍留在本地，由内容仓管理；不是删除用户资源。

## 恢复方法

三个项目并列放置，分别检出 `v0.0.1`。在 Shirone 中安装依赖后运行 `pnpm content:sync`，再运行 `pnpm dev`。同步生成的 `src/user/user-config.ts`、文章与图片副本不作为独立编辑源。

本地 Git 标签会固定三个项目各自的提交，后续修改不会改变这个快照。
